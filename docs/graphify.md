# Explore ContextOS with Graphify

Graphify is an optional developer tool, not a backend dependency or API endpoint.
It helps explore code symbols, imports, calls, and related modules across the API,
web app, and shared packages. The project's commands use local code extraction:
no AI provider, API key, or cloud account is required.

## Setup

Graphify 0.8.40 was used for this integration. If it is not installed on another
machine, install the official `graphifyy` package (double **y**) with Python 3.10+
and uv:

```sh
uv tool install graphifyy==0.8.40
graphify --version
```

The executable is called `graphify`, not `graphifyy`. Ensure it is on your PATH.
See the [official repository](https://github.com/Graphify-Labs/graphify).

## Build and view

From the repository root, using the Node version in `.nvmrc`:

```sh
nvm use
pnpm graph:build
pnpm graph:tree
open graphify-out/graph.html
```

`open` is the macOS command; on other systems open the HTML file in a browser.

- `graphify-out/graph.html`: interactive relationship graph; search and select nodes.
- `graphify-out/GRAPH_TREE.html`: folder and symbol hierarchy, generated by `graph:tree`.
- `graphify-out/GRAPH_REPORT.md`: generated architecture summary and communities.
- `graphify-out/graph.json`: machine-readable graph used by the query commands.

Run `pnpm graph:build` after code changes; the graph is a snapshot, not a live view.
Regenerate the tree separately with `pnpm graph:tree`. For very large graphs,
Graphify may skip the relationship HTML; the report, queries, and tree remain useful.

## Find implementation details

```sh
pnpm graph:query "authentication"
pnpm graph:query "Google Drive"
pnpm graph:query "sources"
pnpm graph:query "workspace"
```

Copy a symbol name from the results to inspect its neighbors or possible impact:

```sh
pnpm graph:explain "createApp"
pnpm graph:affected "createApp"
```

Queries return relevant graph context, not a guaranteed natural-language answer.
Always inspect the linked source before changing behavior: dynamic routing,
dependency injection, runtime permissions, and external systems may not be fully
represented by static analysis. A graph is not proof of feature completeness or
production readiness.

## Scope and privacy

`.graphifyignore` excludes dependencies, build output, environment files, databases,
keys, logs, generated migration metadata, and the superseded five-day roadmap.
Generated graphs are Git-ignored and excluded from Prettier because they are
rebuildable and can contain source snippets and local paths. Do not publish them
without reviewing their contents. HTML viewers may load rendering libraries from
a CDN; local extraction does not mean the browser viewer is fully offline.

This initial integration indexes code and structurally parses supported Markdown
documents, including headings and links in the PRD and guides. It does not perform
AI semantic analysis of those documents or execute Bruno requests. Continue using
`docs/backend-api-use-cases.md` and `bruno/contextos-api/README.md` for API workflows.
Graphify's optional semantic
extraction can include documents, but configuring a model or transmitting project
content to an AI provider is a separate opt-in step.

No Git hooks, global assistant settings, or runtime services are installed by these
project commands. If a rebuild refuses to replace a substantially smaller graph
after intentional code deletion, review the warning before manually using
`graphify update . --force`.
